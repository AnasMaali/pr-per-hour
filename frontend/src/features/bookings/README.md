# Bookings (frontend)

Client booking creation, listing, details, and cancellation.

## Status

Implemented:

- `/dashboard` overview (recent bookings preview)
- `/dashboard/bookings` list with filters/pagination
- `/dashboard/bookings/new` create form
- `/dashboard/bookings/:id` details + cancel dialog
- Service Details CTA → create booking with `?service=<slug>`

Not implemented:

- Admin booking UI
- Payment / invoice
- Reschedule / calendar
- Email/SMS
