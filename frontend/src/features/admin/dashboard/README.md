# Admin dashboard foundation

Admin layout overview and operational snapshot for PR Per Hour.

## Status

Implemented:

- `/admin` overview page
- AdminDashboardLayout (sidebar, mobile drawer, topbar)
- Accurate metrics from API pagination / public catalogs
- Recent bookings and contact-message previews (read-only)
- Quick links to admin management sections + public site
- EN/AR, RTL/LTR, light/dark/system

Also implemented in sibling admin features:

- Categories, services, bookings, and contact-messages management UIs

Not implemented:

- User management
- Payments / invoices / chatbot
- Charts or analytics
