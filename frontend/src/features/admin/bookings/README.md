# Admin Bookings (React)

Admin booking list, details, status, meeting link, and notes UI.

See [docs/ADMIN_BOOKINGS_UI.md](../../../../../docs/ADMIN_BOOKINGS_UI.md).

## Public surface

- `AdminBookingsPage` — `/admin/bookings`
- `AdminBookingDetailsPage` — `/admin/bookings/:id`

## Notes

- Notes are shared booking notes (client-visible)
- Restore/delete booking endpoints are not part of this UI
- Payment/invoice/reschedule are out of scope
