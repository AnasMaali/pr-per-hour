# Public Contact (React)

Public contact form for PR Per Hour.

See [docs/PUBLIC_CONTACT_PAGE.md](../../../../docs/PUBLIC_CONTACT_PAGE.md).

## Public surface

- `ContactPage` — `/contact`

## Notes

- Fields: `full_name`, `email`, `phone`, `organization`, `message`
- No subject, attachments, reply, or outbound email
- Success returns receipt `id` / `status` / `created_at` only
